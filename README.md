# 声线练习室 · 剧团台词排练

纯前端（Vite + React + TypeScript）的剧团共用排练页面，解决多人共用一台设备/一个页面时「抢录、看不出轮到谁」的问题。**不增加任何运行时依赖**，数据全部保存在浏览器本地（localStorage）。

## 用法

```bash
npm install
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建
```

## 三个工作台（页面与数据均分开整理）

1. **剧本资料**：一句一条维护台词，每条带角色与顺序；支持新增/编辑/上移下移/移除、维护出场角色。
2. **排练交接**：
   - 先在顶部选择「我是哪个角色」（可加署名），选择随本地保存；
   - 只有轮到当前台词所属角色时录音按钮可用，轮到别人时保留当前演员的选择与署名，并提示当前该谁录，无法抢录；
   - 录完当前句后点「交给下一句」，指针跳到下一角色的第一句未录台词；
   - 关闭/退出页面再回来，停在上次的句子；全部录完显示本轮完成。
3. **待重排（交接确认）**：
   - 导演**改变已录台词顺序、移除已录台词、或把台词改派给其他角色**时，相关录音自动进入待重排队列，在确认前不会丢失；
   - 每条可「接回这句」（台词还在）、「恢复台词并接回」（台词已删），丢弃需要二次确认；
   - 下方台账按顺序列出每句的录音与录制人，可一键清空从头复排。

## 本地存储（三个独立 key，互不影响）

| key | 内容 |
|---|---|
| `sound-lab-script-v1` | 剧本资料：剧名、角色、台词（角色 + 顺序） |
| `sound-lab-handoff-v1` | 排练交接：当前句指针、当前演员选择与署名 |
| `sound-lab-recordings-v1` | 本轮正式录音记录 |
| `sound-lab-pending-v1` | 待重排队列（含失联台词快照） |

说明：录音目前沿用原有界面的**模拟录音**（记录时长、时间、录制人），不采集真实音频数据；后续接入真实录音时只需替换 `RehearsalPage` 中的开始/结束逻辑，存储与交接规则不变。
